Graphim es un editor visual de grafos y algoritmos hecho en Godot. Desarrollado como proyecto final de matemáticas discretas para 2026-1.

2. Helberth Rodriguez

## Instalación local
1. Clona este repositorio

    ```bash
    git clone https://github.com/Andresit1524/graphim
    cd graphim
    ```
    
2. Instala [Godot 4.7.1](https://godotengine.org/download/archive/4.7.1-stable/) y sus plantillas de exportación. También puedes instalar estas últimas desde el editor de Godot (recomendado):

    _Editor $\rightarrow$ Administrar plantillas de exportación_

3. Abre el proyecto
4. Exporta para Windows tras instalar las plantillas de exportación en

    _Proyecto $\rightarrow$ Exportar $\rightarrow$ Exportar todo $\rightarrow$ Versión de publicación_
